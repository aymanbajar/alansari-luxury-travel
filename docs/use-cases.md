# Use Cases

## Admin Use Cases

1. Admin signs in securely.
2. Admin manages staff accounts and role assignments.
3. Admin creates and updates vehicle records.
4. Admin creates and updates driver records.
5. Admin views all bookings and operational conflicts.
6. Admin reviews reports and exports files.
7. Admin reviews audit logs.
8. Admin updates system settings such as timezone and operational defaults.

## Staff Use Cases

1. Staff signs in securely.
2. Staff views booking dashboard.
3. Staff searches available vehicles and drivers.
4. Staff creates a draft or confirmed booking.
5. Staff updates booking information within permissions.
6. Staff views the timeline for current and upcoming bookings.
7. Staff accesses customer details needed for booking operations.

## System Use Cases

1. System validates all API requests.
2. System prevents overlapping active bookings for the same vehicle or driver.
3. System stores timestamps in UTC.
4. System records audit logs for important actions.
5. System returns consistent API responses and errors.
6. System exposes health status for local and deployment checks.
