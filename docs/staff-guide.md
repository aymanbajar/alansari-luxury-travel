# Staff Guide

## عربي

يمكن للموظف إنشاء وتحديث الحجوزات حسب الصلاحيات، وعرض المركبات والسائقين والعملاء والجدول الزمني.

إرشادات مهمة:

- تحقق من توفر المركبة والسائق قبل حفظ الحجز.
- إذا ظهر تحذير تعارض، اختر بديلاً أو عدّل وقت الحجز.
- لا يمكن للموظف الوصول إلى إدارة الموظفين أو إعدادات النظام.
- الحجوزات المكتملة لا تعدل من حساب الموظف.
- استخدم التقارير التشغيلية فقط للمهام اليومية.

## Common Workflow

1. Open the dashboard.
2. Review today's dispatch and timeline.
3. Create or find the customer.
4. Create the booking and confirm availability.
5. Use report exports only when needed for operations.
